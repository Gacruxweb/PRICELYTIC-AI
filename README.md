# Pricelytic AI

Pricelytic AI is a professional-grade price comparison and market analysis dashboard. It leverages Gemini AI to perform deep product searches across both international and local marketplaces with intelligent logic for regional stores.

## Key Features

*   **Intelligent AI Search:** Context-aware searches that understand brand models and regional availability.
*   **Visual Search:** Upload or capture a product image to identify and compare prices automatically using Gemini Vision.
*   **Multi-Currency System:** Real-time conversion between USD, BDT, EUR, GBP, JPY, INR, and AED with dedicated formatting and professional icons.
*   **Price History Tracking:** Interactive charts visualizing historical price trends to identify true market "deals."
*   **Smart Watchlist:** Firebase-backed price drop alerts and product tracking for authenticated users.
*   **Dual-Aesthetic UI:** Polished high-contrast Light Mode and a deep-space Dark Mode with professional typography and centered container layout.
*   **Data Analysis:** One-click CSV export for offline price analysis and competitor comparison.

### Run Locally

**Prerequisites:**  Node.js

1.  **Install dependencies:**
    ```bash
    npm install
    ```
2.  **Environment Setup:**
    Create a `.env` file (see `.env.example`) and set your `GEMINI_API_KEY`.
3.  **Launch the app:**
    ```bash
    npm run dev
    ```
